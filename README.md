# PoliTo Exam Trainer

Practice tests for first-year courses at Politecnico di Torino: **Analisi I**, **Chemistry** and **Computer Science (14BHD)**.

- **Computer tests** with the real exam format (timer, question navigation, exam scoring).
- **Written exams** with full solutions and a grading rubric; upload photos of your work.
- **Practice by topic**, with the solution right after each answer.
- **History and statistics** per topic. Create an account to keep your history on every device.

Every question is generated from a template with random parameters, and the correct answer is computed by the program
(exact fractions and Taylor expansions for Analisi, the exam tables for Chemistry, Python semantics for CS).

Unofficial project, not affiliated with Politecnico di Torino.
